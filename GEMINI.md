# Project Guidelines

## Git Workflow
- **Commit Early and Often**: Commit minor changes, refactors, and feature increments to git as soon as they are implemented and verified.
- **Atomic Commits**: Keep commits focused and granular so that each change can be easily reviewed or rolled back if needed.
- **Clear Commit Messages**: Follow conventional commit conventions (e.g., `feat: ...`, `fix: ...`, `ui: ...`, `docs: ...`).
